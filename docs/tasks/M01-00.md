## Objective

Perform a bounded, non-mutating discovery of the locally installed Cursor CLI ACP interface and record environment-neutral evidence for later sandboxed proofs of concept.

## Scope

In scope:

- Confirm `cursor-agent` availability and reported version.
- Confirm the `acp` subcommand and capture its documented options.
- Capture top-level CLI help relevant to authentication, workspace, and session controls **without** exercising them.
- Document verified versus unverified capabilities.

Out of scope:

- Live ACP sessions.
- Coding-agent execution.
- Authentication flows (`login`, credential inspection, whoami).
- Installs, upgrades, configuration changes.
- Network or remote service calls initiated for discovery.
- Autonomous work on real projects.
- Claiming ACP or SANDBOX gate PASS.

## Prerequisites

1. Engineering OS repository.
2. Branch `docs/m01-00-acp-discovery` with a clean working tree before edits.
3. M00-02 merged into `main` (verified via local Git history).
4. External sandbox remains mandatory before M01-01.

## Acceptance criteria

1. Only authorized files are modified or created.
2. Discovery uses only non-mutating local commands.
3. Findings distinguish observed facts, documentation-derived claims, inferences, and unknowns.
4. No live ACP session is started.
5. Validation evidence is recorded in [`docs/validation/M01-00-cursor-acp-discovery.md`](../validation/M01-00-cursor-acp-discovery.md).
6. English-only content; no sensitive host details.
7. ACP runtime gate remains `NOT_TESTED`.
