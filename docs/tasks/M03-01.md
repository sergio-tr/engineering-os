## Acceptance criteria (M03-01)

1. Fixed P1–P8 catalog executed under Owner triple gate with fail-closed runner.
2. Evidence layers separated (launcher / argv / inspect / behavioral).
3. CPU attributed via container cgroup `cpu.max` + throttle delta (B2).
4. Capabilities attributed via process Cap* + NoNewPrivs (B2/B3).
5. keep-id attributed via host-side maps + ownership UID/GID (B3); in-container maps alone insufficient.
6. Cleanup verified for normal and abnormal paths; no residual PoC containers reported.
7. Synthetic fixtures only; no live ACP; no SANDBOX PASS claim.
8. Evidence files present and SHA-256-verified in the Owner store.

## Explicit non-claims

- M03-01 PASS ≠ SANDBOX PASS.
- M03-01 PASS ≠ permission to run live Cursor ACP or real projects.
- Configuration flags / argv alone are not enforcement proof.
- Gaps versus full design/threat model (disk quota, SSH-agent negative test, GitHub-cred negative test, explicit PID/IPC isolation, ACP launcher integration) remain for **M03-02**.
