## Objective

Provide a fail-closed, host-side executable test runner for P1–P8 using rootless Podman, synthetic fixtures, and layered evidence capture. Phase B2 closes remaining runtime evidence gaps for CPU quota enforcement, Linux capability dropping, and rootless user-namespace keep-id mapping. **This increment does not authorize agents to launch containers.**

## Evidence model (required)

Isolation claims must separate:

1. **Launcher configuration** (`planned_controls`)
2. **Executed argv** (safety scan only; **not** enforcement proof)
3. **Runtime-inspected configuration** (`podman inspect`, read-only)
4. **Behavioral negative-test evidence** (probes, canaries, attributable limit signals)

Argv inspection alone must never produce a PASS for isolation controls.

## Phase B2 — Runtime security evidence closure

- R1: P6 CPU subprobe samples the **container cgroup** `cpu.max` and `cpu.stat`; requires quota matching `--cpus=0.50` and attributable throttle delta (`nr_throttled` / `throttled_usec`). Missing/deleted cgroup → `NOT_TESTED` (never PASS).
- R2: Synthetic identity probe reads `CapInh`/`CapPrm`/`CapEff`/`CapBnd`/`CapAmb`, `NoNewPrivs`, `Seccomp` from `/proc/self/status`. Nonzero capability sets FAIL; unavailable fields → `NOT_TESTED`.
- R3: Same probe records euid/egid, `uid_map`/`gid_map`, workspace/marker ownership; keep-id must match host identity. Inspect booleans alone are insufficient.
- R4: Evidence layers remain distinct; historical Owner evidence files are not rewritten. Final M03-01 acceptance treats P6 incomplete until CPU is independently accredited.
- R5: Implementation/static validation only in this pass — no container execute, no Owner triple gate, no pulls/installs.
- R6: Unit tests cover mocked cgroup/procfs success and failure cases without launching containers.
