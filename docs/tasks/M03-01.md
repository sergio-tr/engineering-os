## Objective

Provide a fail-closed, host-side executable test runner for P1–P8 using rootless Podman. Phase B3 corrects keep-id attribution for **nested rootless user namespaces** without weakening isolation policy. **This increment does not authorize agents to launch containers.**

## Defect corrected (B2 → B3)

B2 compared the second column of an **in-container** `/proc/self/uid_map` directly to the launching host UID. Per `user_namespaces(7)`, that column is relative to the **reader's** user namespace. Inside a nested rootless container, `1000 0 1` can mean “container 1000 → parent-userns 0”, where parent 0 later maps to host 1000. Treating `0` as the launching host UID produced a false FAIL.

B3 requires host-side reads of `/proc/<container_pid>/{uid,gid}_map` (and `ns/user`) from the launching process, with PID↔container linkage and PID-reuse guards. In-container map text alone cannot PASS.
